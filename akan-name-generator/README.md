# Akan Name Generator

## Author

Thomas

## Description

This is a simple web application that generates an Akan name based on a user's date of birth and gender. Users enter their birth date, select their gender, and the application displays their Akan name according to the day of the week they were born.

## Features

* Enter date of birth
* Select gender
* Generate Akan name
* Displays the day of the week born
* Simple and responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Setup Instructions

1. Clone or download this repository.

```bash
git clone https://github.com/thomaskamau7588-star/akan-name-generator.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.
